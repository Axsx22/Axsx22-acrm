# ACRM Benchmark v1.1 — repository reference

The authoritative benchmark artifact supplied with the ACRM research package is `ACRM_Benchmark_v1_1.pdf` (uploaded source: ACRM_Benchmark_v1_1 (1).pdf).

This repository copy records the benchmark specification and traceability boundary. The benchmark is a proposal/protocol, not a claim that all large-scale experiments have already been executed.

## Benchmark families

- TEST-01 — Modularity
- TEST-02 — Self-regulation
- TEST-03 — Alert accuracy
- TEST-04 — Non-interference
- TEST-05 — Audit integrity
- TEST-06 — Input monitoring
- TEST-07 — Multi-model compatibility

## Evidence boundary

Existing demos and unit/integration tests are evidence of implementation behavior. They are not substitutes for the independent, large-scale benchmark runs defined by the benchmark protocol.
