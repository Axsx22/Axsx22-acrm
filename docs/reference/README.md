# ACRM Reference Corpus

This directory is the canonical repository index for the ACRM research corpus.

## Primary references

- `ACRM_Whitepaper_v1.1.md` — canonical architecture reference copy.
- `ACRM_Benchmark_v1_1.md` — ACRM-EVAL benchmark protocol reference.
- `ACRM_Benchmark_v1_1_source.txt` — provenance record for the supplied benchmark PDF.
- `ACRM_Appendix_A_Field_Ontology_v1.2.md` — canonical field ontology reference.
- `ACRM_Evolution_Roadmap.md` — unified research lineage and artifact taxonomy.
- `SOURCE_ARTIFACTS_MANIFEST.md` — source filenames, roles, statuses, and SHA-256 hashes for the supplied corpus.

## Evidence boundary

The reference corpus intentionally distinguishes:

1. canonical architecture;
2. executable implementation;
3. demonstration artifacts;
4. mathematical/research specifications;
5. benchmark protocols;
6. empirical benchmark results.

Presence in this directory does not convert a research proposal into an empirical result.

## Session C boundary

Session C is experimental governed-evolution work. It must not be described as production-validated autonomous self-modification. Its current boundary is candidate generation, independent testing, topic-aware review, and switch recommendation without active-runtime mutation.
